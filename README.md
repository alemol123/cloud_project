# MealFlow
Group members: Alexandra Molins, Luna Larcher, Khadeja Nehad, Lorenzo Hoffman, Ali

URL: https://alemol123.github.io/cloud_project/

Simplified Serverless Uber Eats–like platform using Microsoft Azure services with a static frontend hosted on GitHub Pages that calls the backend services. The platform supports two -sided interaction between:

- Restaurants, who register and publish meals
- Customers, who browse meals in their delivery area and place orders
